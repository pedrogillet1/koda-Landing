Jurídico

Integrações e Uso de Dados

Como o Allybi acessa fontes conectadas, quais permissões são usadas e como dados de integrações são processados dentro do seu workspace.

Última atualização: April 30, 2026 Versão: 1.0
Esta página contém texto jurídico em inglês enquanto a versão em português passa por revisão. Em caso de dúvida, entre em contato com a Allybi.

1. Overview

Allybi connects to external services to help you bring files, email context, and message handoff into one private workspace. This page explains exactly what data each integration accesses, how it is used, and how to disconnect.

2. Available Now

Outlook

Status: Live

Data accessed: Selected emails, threads, attachments, and metadata.

Used in: Search and chat workflows, Integrations, and review-before-send workflows.

Storage: Stored in your workspace.

OneDrive

Status: Live

Data accessed: Selected files, folders, and metadata.

Used in: Upload and chat workflows.

SharePoint

Status: Live

Data accessed: Selected sites, libraries, folders, and files.

Used in: Upload and chat workflows.

Google Drive

Status: Live

Data accessed: Selected files and folders.

Used in: Upload and chat workflows.

WhatsApp

Status: Ready

Data stored: Contacts, message drafts, and selected references.

Used for: Message handoff with review before opening WhatsApp. NOT a synced inbox.

Allybi does not automatically send WhatsApp messages. You review and confirm before the message is handed off to WhatsApp.

3. Coming Soon

Gmail

Status: Coming soon

Data accessed (when enabled): Selected threads, messages, and attachments.

4. What Disconnect Does

When you disconnect an integration, Allybi stops using that connection to access new data from that service. Previously imported files, message drafts, metadata, or cached items may remain in Allybi until you delete them, your workspace settings delete them, or our retention rules require deletion. Disconnecting an integration does not automatically delete files or content already imported into Allybi unless the product specifically says so.

5. How to Delete Imported Content

You can remove imported content from Allybi in the following ways:

  • Individual file deletion: Delete specific files directly from your workspace.
  • Workspace deletion: Delete your entire workspace to remove all associated content.
  • Account deletion request: Email info@allybi.co to request full account and data deletion.

6. OAuth and Permissions

Allybi uses OAuth 2.0 to authenticate with third-party services. We request least-privilege scopes, meaning we only ask for the minimum permissions required to provide the integration features you use. OAuth tokens are encrypted at rest.

You can revoke access at any time by disconnecting the integration through your Allybi account settings.

7. No Training, No Ads, No Sale

Your documents are yours. User documents never train AI models, are never sold to third parties, and are never used for advertising purposes.

8. Google API Services User Data Disclosure

Allybi’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically:

  • Allybi only uses access to Google user data to provide and improve user-facing features that are visible and prominent in the application’s user interface.
  • Allybi does not transfer Google user data to third parties unless necessary to provide or improve user-facing features, to comply with applicable laws, or as part of a merger, acquisition, or asset sale with prior user notice.
  • Allybi does not use Google user data for serving advertisements, including retargeting, personalized advertising, or interest-based advertising.
  • Allybi does not allow humans to read Google user data unless the user has provided affirmative consent, it is necessary for security purposes, to comply with applicable law, or the data is aggregated and anonymized for internal operations.

9. Microsoft 365 / Microsoft Graph Data

Outlook, OneDrive, and SharePoint integrations use Microsoft Graph API with delegated permissions. Allybi requests least-privilege scopes and only accesses data you explicitly select or authorize.

When you disconnect a Microsoft integration, Allybi immediately stops accessing new data from that service. Previously imported content remains in your workspace until you manually delete it or request account deletion.

Allybi does not use Microsoft 365 data for advertising, AI model training, or any purpose other than providing the integration features you use.

10. Contact

For questions about integrations and data use, contact us at info@allybi.co.
