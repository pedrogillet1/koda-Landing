# Positioning Strategy — Allybi

---

## Target Audiences

**Primary:** Brazilian lawyers handling sensitive documents — contracts, due diligence, regulatory filings.

**Secondary (future):** Finance teams, compliance officers, operations managers dealing with confidential documentation.

## Category Definition

> Private workspace for sensitive documents.

Not an "AI tool." Not a "copilot." A workspace where professionals work with confidence on documents that matter.

## Core Promise

**Find, compare, act — with confidence.**

## Trust Pillars

| Pillar | Meaning |
|--------|---------|
| **Grounded** | Every answer traces back to a source document |
| **Confirmation** | The system asks before acting, never assumes |
| **No training** | User data is never used to train models |
| **Human control** | Humans approve every action |
| **Encryption** | End-to-end, at rest and in transit |
| **Version awareness** | Always working on the correct document version |

## Brand Voice

- **Calm** — No urgency tactics, no hype
- **Professional** — Speaks like a colleague, not a salesperson
- **Specific** — Concrete scenarios, not abstract promises
- **Trustworthy** — Shows how it works, doesn't just claim it works

## Primary CTA

- PT-BR: **"Agendar demonstracao"**
- EN: **"Book demo"**

## What We Do NOT Say

| Avoid | Why |
|-------|-----|
| "AI-powered" | Overused, triggers skepticism |
| "Copilot" | Implies the AI leads; we want human control |
| "Revolutionary" | Hype language, erodes trust |
| "Magic" | Opposite of our grounded positioning |
| "Automate everything" | Conflicts with human-control pillar |

## Competitive Frame

We do not compete with general AI assistants. We compete with the current workflow: manual search, side-by-side tabs, copy-paste comparisons, and version confusion. The enemy is wasted time on high-stakes documents, not other software.
